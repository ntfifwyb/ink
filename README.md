# anki-dashboard

An Anki add-on that replaces four stats add-ons (Review Heatmap, More Decks Stats and Time Left, Study Time Stats, and an extra deck-columns add-on) with one minimal, information-dense design: monochrome with an amber accent, across the deck list, deck overview, reviewer and stats page.

Status: not yet implemented. The build spec is in [docs/spec.md](docs/spec.md); the screen it replaces is [docs/current-main-screen.png](docs/current-main-screen.png).
